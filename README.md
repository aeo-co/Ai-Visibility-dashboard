# AI Visibility Dashboard
This is a premium dashboard that visualizes data from `AI visibility report.csv`.

## How to View

**Good news!** You do **not** need to install Python or Node.js anymore.

1. **Locate `index.html`** in this folder.
2. **Double-click it** to open it in your browser.
3. You will see an **Upload Screen**.
4. Click **"Select CSV File"** and choose the `AI visibility report.csv` file from this folder.
5. The dashboard will generate instantly.

That's it!
